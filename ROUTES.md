# GlobeTrek Adventures — Route Map

## Portal 1: Customer

- `/GlobeTrek/` — discovery/home
- `/GlobeTrek/packages.php` — browse/search packages
- `/GlobeTrek/package.php?id=ID` — package details
- `/GlobeTrek/login.php` — customer login
- `/GlobeTrek/register.php` — registration
- `/GlobeTrek/book.php?id=ID` — customize and book
- `/GlobeTrek/bookings.php` — booking history/status
- `/GlobeTrek/payment.php?id=ID` — PayHere checkout
- `/GlobeTrek/payment_notify.php` — verified PayHere server callback
- `/GlobeTrek/payment_return.php` — payment return
- `/GlobeTrek/queries.php` — customer inquiries

## Portal 2: Management (role-based Staff/Admin)

- `/GlobeTrek_Management/login.php` — shared staff/admin login
- `/GlobeTrek_Management/index.php` — role-aware dashboard
- `/GlobeTrek_Management/bookings.php` — booking workflow, assignment and supplier coordination
- `/GlobeTrek_Management/packages.php` — package CRUD
- `/GlobeTrek_Management/services.php` — hotel/transport service catalogue
- `/GlobeTrek_Management/queries.php` — inquiry response
- `/GlobeTrek_Management/admin/users.php` — admin-only account/role management
- `/GlobeTrek_Management/admin/reports.php` — admin-only sales/demand reports
- `/GlobeTrek_Management/admin/settings.php` — admin-only settings
